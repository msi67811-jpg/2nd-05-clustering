## 변화 패턴 군집 설명

고객이 지금 얼마나 쓰는지가 아니라, 최근에 어떻게 바뀌었는지로 묶은 군집입니다.

### 변수
- 거래건수·거래금액 변화율(Q4/Q1), 비활성 개월, 절대 거래건수

### 모델
- StandardScaler + K-means (k=3)
- Elbow·실루엣로 k 비교 후 해석 편의상 k=3 확정

### 해석
- 급감형 / 완만감소형 / 안정·증가형
- 이탈 여부는 군집에 미사용, 사후 이탈률 비교만 수행
- 평균 거래건수 변화율

- ## 군집 네이밍 기준 (평균 거래건수 변화율)

K-means로 나눈 3개 군집에, 군집별 **평균 `Total_Ct_Chng_Q4_Q1`** 을 보고 이름을 붙였습니다.

| 이름 | 의미 | 기준 (군집 평균 변화율) |
|---|---|---|
| 급감형 | 4분기에 이용이 크게 감소 | < 0.65 (Q1의 65% 미만) |
| 완만감소형 | 완만하게 감소 | 0.65 ~ 0.85 |
| 안정·증가형 | 유지되거나 증가 | ≥ 0.85 |

- 변화율 예시: `0.5` → 4분기 거래가 1분기의 약 50% → 급감형에 해당
- 모델이 자동 생성한 이름이 아니라, 결과 해석용으로 붙인 라벨입니다.
